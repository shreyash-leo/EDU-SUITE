# User journeys

| Journey | Entry and goal | Dependencies, validation and completion |
| --- | --- | --- |
| Organization onboarding | Super Admin creates or opens an organization and starts setup. | Register schools, record subscription and commercial details, add administrator, then satisfy activation checks. Drafts preserve incomplete work; activation exposes credentials for manual delivery. |
| School structure | Organization admin selects school and academic year. | Configure board, grades, sections and classrooms within organization-wide allowance; save a draft, review impact and validation, then publish. Published versions remain unchanged during editing. |
| Bell and calendar | Open school configuration and Bell Time & Calendar. | Set default timings, holiday and advanced rules, review conflicts and date coverage. Existing published rules and migration behavior remain in force. |
| Administrative maintenance | Open a record or settings page and edit. | Role checks and validation apply; navigation guard offers save/discard where changes are pending. Successful persistence or explicit discard returns the user to the workspace. |

Full analysis of error recovery, repeated selection, focus order and completion feedback remains outstanding for each journey.
